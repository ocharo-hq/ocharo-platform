# v0.3 — Events on WoW2 Events

*Last updated: 2026-11-10*

**Status:** 🔄 In progress · **Type:** Adoption · **Started:** 2026-11-10

Desk's Events move onto WoW2 Events (`wow-two-sdk-beta.events`), which owns the catalog and tracking; Desk keeps its
page, membership and references. Picks and reasons: [events-adoption.md](../../../research/events-adoption.md) #1–#12;
the cross-lane track is `wow-two-ws` `system/sessions/events-integration/events-integration.md` (`events-integration`).

### Iteration 1 — Export to WoW2 Events

- [x] Ability to export an organization's events as a `wow2.events-import.v1` bundle (`export events`)
- [x] Keep each Desk id, key, stage, priority, notes and provenance in the bundle
- [x] Keep month and estimated precision on the 1st, estimated never announced
- [x] Mark every title's language undetermined
- [x] Refuse an existing bundle file or an unknown organization
- [x] Dry-run the export on local Desk → 68 of 68 rows, 68 unique ids
- [x] Reshape the export onto Events' fixed import schema (`rows`, `facts`, `yyyy-MM` months)

### Iteration 2 — Registrations in Ocharo's Identity

- [x] Add resource `events` with its scopes, namespace and signal URL
- [x] Add SCFD's resource `harvest` with its 11 scopes
- [x] Add client `events` and `harvest-operator` by client credentials
- [x] Add Desk's token exchange to `events`
- [x] Grant `events:*` permissions to owner, admin, editor and viewer
- [x] Add client `events-console` for the review console's sign-in
- [x] Let `events-console` reach `events` for a reviewer by token exchange

### Iteration 3 — Desk on the Events service

- [x] Ability to read Desk's Events page from WoW2 Events through Desk's routes
- [x] Ability to propose an event from Desk as a candidate in Events
- [x] Ability to track an event's stage, priority and notes through Desk's routes
- [x] Refuse Desk's old event writes and `import events` once Events serves Desk
- [x] Ability to roll back to Desk's own table until reconciliation passes
- [x] Keep the Vue screens unchanged on Desk's routes, served from Events
- [x] Adopt Events Client `10.0.0-beta` and be sdk `10.0.111-beta`

- [x] Reconcile counts, stage, priority, notes, provenance and precision → 68 of 68, 0 mismatches
