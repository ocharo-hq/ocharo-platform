# v0.3 — Events on WoW2 Events

*Last updated: 2026-11-10*

**Status:** 🔄 In progress · **Type:** Adoption · **Started:** 2026-11-10

Desk's Events move onto WoW2 Events (`wow-two-sdk-beta.events`), which owns the catalog and tracking; Desk keeps its
page, membership and references. Picks and reasons: [events-adoption.md](../../../research/events-adoption.md) #1–#12;
the cross-lane track is `wow-two-ws` `system/sessions/events-integration/events-integration.md` (`events-integration`).
