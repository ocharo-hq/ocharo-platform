# OcharoEvents.Api

*Last updated: 2026-11-20*

The HTTP host: the Events page's mirror of WoW2 Events (`Events/`, OE07), the Telegram delivery's digest routes
(`Delivery/`), Identity BFF sign-in (sessions and key ring in PostgreSQL), the organization access filter (#4), the WoW2
Events client composition, the event image route's Files client (`Files:BaseUrl`, `Files:ApiKey`, optional; without them the route redirects to the image's source link), runtime config, status and the SPA bundle. Verbs: the be sdk's `migrate` and `config check`.
