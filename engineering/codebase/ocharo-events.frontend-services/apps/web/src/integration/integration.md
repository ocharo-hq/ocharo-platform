# Integration

_Last updated: 2026-11-19_

Endpoint clients over the SDK transport: the Identity BFF session, runtime settings, the API status, and the
`fe-events` client over this app's mirrors of WoW2 Events (`events/EventsClient`: the session's CSRF token on writes, the
session re-read after a 401 or 403), used for the Events page (`/events-api`, OE07) and the digest editor (`delivery/`).
