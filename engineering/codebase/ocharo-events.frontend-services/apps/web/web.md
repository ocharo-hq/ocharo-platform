# Web

*Last updated: 2026-11-20*

Events' Vue 3 operator app on the shared `AppFrame`, with its own side navigation like Brand's: the feed, the calendar, and Settings with the reminders and, for an admin, the Telegram delivery (a bottom bar of the same places on a phone). Sources in `src/`, unit tests in `tests/`, stable-name files (icons, splash, first-paint styles) in `public/`.
