## Implementation choices

A normalized snapshot stores page dimensions and element geometry in millimetres. Template imagery is curated
into static assets; uploaded imagery uses the existing authenticated media service. Snapshots contain references,
not base64 images. Catalogue pages, text, prices and photo frames remain editable objects. One renderer drives the
interactive page; a matching canvas renderer produces high-resolution image PDFs to preserve all three scripts.
PDF text is rasterized in this increment. Saved editable JSON retains text and layout; PDF is an output, not the
source of truth. Business-card output uses the source's 85×55mm trim dimensions without claiming printer bleed approval.

The frontend adopts the current pnpm workspace layout (`apps/web`, reserved `packages/*`) and keeps the API's
ordinary build responsible for packaging the SPA. Dependencies use published packages, not sibling source imports.
jsPDF 4.2.1 was selected from its [official release](https://github.com/parallax/jsPDF/releases/tag/v4.2.1).
