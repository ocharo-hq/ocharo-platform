# Ocharo Catalogue — Product

*Last updated: 2026-09-28*

The catalogue editor for Ocharo: one place to keep every product's facts, prices, images and collections correct, then reuse them everywhere.

## Who

- **Maftuna** (owner/operator) edits products and prices in Uzbek; copy is maintained in uz/ru/en.
- **Sibling platforms** read the public feed: Marketing (cards and captions), the Blog ("pieces in this story"), print exports.

## Surfaces

| Surface | Job |
|---|---|
| Mahsulotlar | Grid with search/filters, bulk status and bulk price changes, duplicate a product as a new variant |
| Mahsulot | Editor: basics, sizes/codes/tags, three-language copy with approval, price tiers, images, review questions, history |
| Matnlar | Three-language copy for all products in one grid; approve per language |
| Narxlar | Every price on one sheet; edits save per cell as drafts |
| Qoldiq | Pieces per size or made-to-order; drives availability in the feed and the order sheet |
| To‘plamlar | Ordered selections; published ones reach the feed |
| Katalog varag‘i | Print-ready lookbook / price list per language, and a merchant order sheet |
| Sozlamalar | Garment families, size preset, contact lines, price note; workspace import; exports |

## Rules

- A product is **active** (in the catalogue and the feed) only with an Uzbek name and at least one image.
- Copy approval is per language; prices are *confirmed* only when the owner says so — bulk edits reset them to draft.
- Imported records keep their original wording, file hash and review questions; nothing is inferred (e.g. 2–9 piece prices).
