# Ocharo Brand — Product

*Last updated: 2026-09-28*

The brand centre for Ocharo: change the logo, colours or links once, publish, and every Ocharo platform picks it up.

## Who

- **Maftuna** (owner/operator) uploads logo versions, edits identity, publishes releases and schedules appearances — UI in Uzbek.
- **Sibling platforms** read the published kit: Catalogue (print sheets), Blog (site header, footer, export), and later Marketing and Studio.

## Surfaces

| Surface | Job |
|---|---|
| Umumiy | What consumers see now, unpublished changes, publish with a note, platforms reading the kit, release history |
| Logotiplar | Upload versions per slot, approve, choose the current one, preview on light/dark/check backgrounds |
| Identitet | Name, spelling rule, uz/ru/en descriptor/tagline/location, palette, typography, links, voice notes |
| Tadbirlar | Schedule time-boxed logo/accent overrides and an event badge link; cancel |
| Ulanish | Stable logo URLs, data/style endpoints, sample code |

## Rules

- Nothing reaches consumers until it is published; a release needs an on-light or master logo.
- Publishing with no changes is refused; every release keeps its full snapshot, so any platform can pin one.
- Appearances never overlap and last at most 92 days; outside the window the release shows unchanged.
- Fallbacks: on-light/social → master; favicon → avatar → on-light.
