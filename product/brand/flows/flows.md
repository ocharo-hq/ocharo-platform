# Flows

*Last updated: 2026-09-28*

1. **New logo** — Logotiplar → slot → upload → approve → make current → Umumiy → publish with a note → platforms pick it up within their cache window (logo URL 5 min, kit 1 min).
2. **Fix a link or colour** — Identitet → edit → save (revision checked) → publish.
3. **Seasonal look or event** — Tadbirlar → name, window, logo override per slot, accent and/or an event badge (label + https link) → the kit switches automatically inside the window; the Blog shows the badge beside its logo.
4. **Connect a platform** — Ulanish → copy the snippet (JSON, stable logo URL or `tokens.css`) → the platform appears in the Umumiy consumer list after its first read.
