# Operator flows

*Last updated: 2026-10-08*

## Prepare and approve

Authenticate → enter authorized brand → select a product/media snapshot → edit a draft → request
review → approve an immutable revision → export a manual publication package.

An edit after approval creates a new revision. A save conflict preserves work. Exporting a package
does not claim that a provider published it.

## Schedule and recover

Choose a connected destination → validate its supported format → select date/time/zone → confirm
the approved revision → schedule → inspect attempts → confirm provider publication → inspect observations.

Unknown send outcomes enter reconciliation; they do not expose a blind retry action. Cancellation
after dispatch begins reports uncertainty rather than promising recall. Reconnection requires
revalidation before affected work resumes.

## Optional Studio handoff

Import original Studio JSON and optional PNG → retain original bytes/schema/hash → associate a
platform-owned creative asset → optionally link it to a separately verified product.

Tenant and campaign metadata live in platform records, not injected into Studio's exact-key document.
Studio's local browser workspace identifier never becomes platform authorization.

## Source materials

Authenticate → open Sourcing → drop supplier photos into the inbox → assign them to suppliers →
record routes and people → move the supplier from lead to quoted → qualify it explicitly after review.

Uploading the same bytes again returns the existing item. Desk never contacts a supplier.
A ledger bundle import adds what is missing and leaves Desk edits untouched.

## Choose where to show

Authenticate → open Events → read the nearest deadlines → review new candidates → shortlist or skip →
record the application route and cost → move the event to applied, confirmed and attended.

Desk records the decision and evidence; applying, paying and registering happen outside Desk.
