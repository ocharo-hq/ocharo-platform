# Ocharo Platform repository instructions

*Last updated: 2026-09-29*

Apply the enclosing [Ocharo workspace instructions](../../AGENTS.md), this repository's
[CLAUDE.md](CLAUDE.md), and the upstream [WoW2 instructions](../../../../../AGENTS.md).
Shared engineering conventions live in the [WoW2 convention index](../../../../../conventions/conventions.md).
The [Ocharo manifest](../../repositories.json) owns checkout navigation and setup.

`ocharo-platform` owns Ocharo Desk, the operator platform. It retains the Brand Workspace
Git history, current source slugs, organization isolation and immutable record identities.
The canonical checkout is inside Ocharo; the former mft path is a temporary compatibility
symlink for the existing review runtime, not another source or setup owner.

Preserve staged and unstaged implementation, private runtime data and other sessions' work.
Keep Studio independently owned and keep original business records in the private workspace.
Planned module consolidation does not establish completed integrations or approved business content.

Follow the target repository's persistent Git flags and native hooks. Moving a repository does not
repair path-bound records; never edit records or replay user events. Instructions and setup grant
no Git or publication permission. Use a WoW2-rooted coding chat for its native hook configuration;
changing a shell working directory alone does not change this chat's active adapter.
